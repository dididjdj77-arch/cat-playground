# ROUTES-AND-IA — 앱/웹 라우팅 및 IA

## 앱 IA
- Tabs: 하우스 / 다이어리 / 소셜 / 설정
- 소셜 세그먼트: 냥스타그램 / 채널 (+추후 알림/내 활동)

## 다이어리 화면
- 상단 인라인 패널 2개(관찰/내 글): 기본 접힘, 저장 시 자동 접힘
- 하단 log_date 그룹 리스트(B1)
- 달력: 다이어리 탭 한 페이지(점프용)

## 하우스 화면(/house)
- 2D 거실 씬 + 슬롯 표시
- 빈 슬롯 탭 → 아이템 선택 모달(is_current=true 목록) → 바인딩 저장
- current 없으면 → "먼저 냥벤토리에서 등록/현재 설정" 안내
- "냥벤토리 관리"로 이동(추가/교체/중단/히스토리)
- "공개/발행 설정"으로 이동

## 냥벤토리 관리 화면(/inventory)
- **홈 탭 (사용중)**:
  - 타입별(사료/모래/장난감/가구) "현재 카드" 목록
  - 각 카드: 아이템명 + 사용 시작일 + 교체/중단 버튼
- **범위 제외(v1)**:
  - 투약/복약은 인벤토리에서 다루지 않고 관찰/계획 도메인으로 분리(D-060)
- **히스토리 탭**:
  - 타입별/고양이별 필터 제공
  - 교체 타임라인: 이전 아이템 목록 (changed_at 기준 정렬)
  - 각 항목: reason_code 배지 + reason_note 표시
- **교체/중단 UX**:
  - 버튼 라벨: "교체" 또는 "중단" 선택 (D-058)
  - 교체 시: 새 아이템 입력 + reason_code(switch) + reason_note
  - 중단 시: reason_code(discontinue) + reason_note (새 아이템 없음)
- See: D-058 (인벤 교체/중단 이벤트 모델)

## 채널 화면(Blind 벤치마킹)
- 검색 + 피드(인기/최신/팔로잉)
- 토픽 탐색/팔로우
- 스레드 상세: 본문 + 답글(1-depth) + 좋아요/신고/차단
- 닉네임 탭: 액션 메뉴(고양이/하우스/냥스타)

## 공개 하우스 보기
- /u/{nickname}/house : 공개 하우스 보기
- **접근**: auth-only (로그인 필수). See AUTHZ-MODEL §0-4.
- **조건 미충족 시**: 404 (존재 은닉)

## 웹 SEO 라우트
- 채널:
  - /c
  - /c/{topicSlug} (index)
  - /c/{topicSlug}/{threadId} (index)
- 공개 냥스타:
  - /p
  - /p/{postId} (index)
- 내부 검색:
  - /search?q=... (noindex)

SEO 정책:
- index: 토픽 랜딩/스레드 상세/공개 글 상세
- noindex: 내부 검색 결과
- 공개 하우스: auth-only이므로 SEO 제외 (v1)
